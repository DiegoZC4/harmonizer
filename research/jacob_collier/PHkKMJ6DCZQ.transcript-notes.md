## Evidence boundaries

### Directly demonstrated in the clip

- real-time MIDI-controlled vocal harmony
- freeze trigger and freeze level
- freeze transposition in both directions, including compound intervals
- glide enable/amount/length
- an open/closed freeze effect and other unnamed transformations

### Documented by Bloomberg's thesis, but not fully specified here

- three independent freeze layers
- latch/release and momentary operation
- infinite reverb implemented historically with the Ambience plugin's hold mode
- reset after release to prevent one sustain from bleeding into the next
- a separate recent-four Antares path for glide
- post-harmony EQ, Mid-Side processing, and MIDI-controlled gates

### Our implementation choices

- a small in-process Freeverb-style diffusion network replaces the historical
  Ambience plugin
- a dual-delay shifter transposes each frozen stereo layer
- the open/closed behavior is implemented as a smoothed low-pass tone sweep
- glide currently follows the prior note across the native voice engines; it
  does not yet duplicate Bloomberg's separate four-voice Antares lane
- chorus and musical reverb are optional post-bus effects and default to off

The phone recording contains room sound, PA, microphone, and the final processed
mix, with no isolated dry input. It is useful for feature and perceptual
comparison, but it cannot support a null test or prove that two algorithms are
timbrally identical.

## Emulator acceptance checks

The repeatable Vocadito test latches a real a cappella phrase, replaces the
input with digital silence, and checks the held output with an FFT analyzer.
The current matrix covers unison, major third up, fourth up/down, fifth up/down,
and octave up. Relative interval error is currently within `5.2-15.7` cents.

Run it with:

```bash
make test-collier-features
```

Results are written to `backend_lab/results/collier_features/`, including JSON
spectrum reports, `interval_accuracy.csv`, rendered WAVs, and spectrograms.
