# Harmonizer Rehearsal Quick Start

Rubber Band Live 512 is the default and recommended native backend.

Download the current packages from:

https://github.com/DiegoZC4/harmonizer/releases/latest

## macOS

1. Download `Harmonizer-macOS-universal.dmg`.
2. Open it and drag Harmonizer to Applications.
3. If the release notes say the build is unsigned, right-click Harmonizer and
   choose **Open** on the first launch.
4. Choose the microphone, headphones, and MIDI input in the browser GUI.
5. Confirm **Rubber Band Live 512**, **100% wet**, and test the output.

The universal package supports Apple Silicon and Intel Macs.

## Windows 10 or 11

1. Download and run `Harmonizer-Windows-x64-Setup.exe`.
2. If the release notes say the build is unsigned, review and accept the
   Windows security warning.
3. Choose the microphone, headphones, and MIDI input in the browser GUI.
4. Confirm **Rubber Band Live 512**, **100% wet**, and test the output.

The portable `Harmonizer-Windows-x64.zip` is available for computers where an
installer is inconvenient.

## Linux x86_64

Download `Harmonizer-Linux-x86_64.AppImage`, then:

```bash
chmod +x Harmonizer-Linux-x86_64.AppImage
./Harmonizer-Linux-x86_64.AppImage
```

Source-build installers remain available in the repository for unsupported
Linux distributions and developers.

## Audio check

Use headphones. Confirm the input meter moves, **Test output** is audible, MIDI
or computer-key notes illuminate the piano, and singing produces wet output.
Use the same sample rate and physical audio devices for the whole rehearsal.

For a performance, bring the microphone, audio interface, headphones, MIDI
controller, power supplies, and an offline copy of the installer. Treat a new
computer as a backup until it passes this check with the exact interface and
output route.
